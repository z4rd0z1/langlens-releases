# LangLens releases

Public download assets (DMGs) for LangLens.

LangLens exists so screen copy can be read and translated in place, on a design, a deck, an email, or anything else, without leaving the page or retyping the text.

Site: [langlens-beta.vercel.app](https://langlens-beta.vercel.app)

App source lives in a separate private repo.
